## Cross-cutting

1. **Dead job.** run.ts still schedules `rivals` (rivals.ts was deleted in N12). Remove the job entry.
2. **Duplicate RefBot runs of the same game.** serving (central seed 2027 to 580 d and to 1200 d), research (mk(2027) to 240 and to 300), evals (seed 2027 to 365), worktypes (seed 2027 to ASI, up to 1825 d) and sites (seed 1, 450 d) each run a RefBot game that the shared fixtures (day400/day900, in scripts/v2/fixtures) already hold. Either read the checks off the fixtures, or route the long runs through simcache like calib/safety do. None of the 18 scripts uses simcache.
3. **Removal checks.** Grep or regex checks for "old flag / old name gone" (currency, domainref, data x3, suites, research x3, oversight, safetyideas x6, worktypes x2, serving S7) are about 20 checks. They cannot fail without a deliberate edit. Move the useful ones into one lint-* script and delete the rest. Several read all of src (domainref, data) or a design archive file (safetyideas).
4. **Old-task ids as check names** (RD-R05, RD-U01/02/05, D9, E1/E2, V1-V4, EV1-EV9). The mechanics are mostly live. Only a few pin old-world numbers: serving line 308 (700M users), evals EV1 ($0.5k) and EV9 (14-day v2), oversight lines 136-139 ("v2 half points"), successor line 186 (0.07), effective line 84 (27.7). These belong to the OPEN.md "re-derive expectations" item.
5. **Waiting for a rare event in a sim.** products line 143 (up to 30000 incident rolls). research taste and "quarter of wins survive" are Monte-Carlo (400-2000 draws, cheap but statistical). Prefer constructed cases.
6. **Same function checked in several scripts.** The level / OOM / domain-reference map is checked in effective (start profile), currency, domainref and oversight (RD-U02). Merge to one place (effective.ts).
7. **Shared setup rebuilt per block.** `newGame(defaultSetupV2(...))` is called about 12 (data), 8 (products), 8 (serving), 9 (research + worktypes + evals) times with identical setup. sites.ts has the right pattern (build once, `structuredClone`). Put it in lib.ts (`cloneGame(setup)`) and use it in data, products, serving, suites, oversight and research.
8. **run.ts `est` values** are fallbacks only; I did not read .simcache/last-run.json (nothing run). Use its timing log to confirm the cost ordering above.
