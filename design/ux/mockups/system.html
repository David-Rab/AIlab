Interaction patterns

Hover = why. Every number shows its causes (ledger strip or formula), ranked, with the levers that move it. Blue terms nest; Alt locks.
Click = go. Every chip, node and cause opens the panel and control that changes it.
Preview before commit. Hovering an option or action ghosts its effect onto the real meters (dashed) before you click.
Causal highlight. Hovering a meter lights every element that feeds it across the screen (nav badge, rail card, map node).
One alert channel. Bottom bar only; nav badges show where action is waiting.
